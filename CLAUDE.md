# Claude Code project instructions

`AGENTS.md` is the canonical repository guidance for every agent. Read and follow it
before making changes. This file carries only Claude-harness-specific notes; it never
restates scope, read order, or process, because those live in `AGENTS.md`, the active
work contract, and the active process protocol.

- Never self-authorize a merge, push, or history rewrite. Merge authority is the
  operator's alone, regardless of how complete the work looks.
- Prefer the repository's own artifacts over conversation memory. If a fact matters to a
  decision, verify it against committed files rather than recalling it.
- Do not add slice-specific instructions to this file. Per-slice scope belongs in the
  work contract and accepted implementation plan, which are hash-pinned; a paraphrase
  here would compete with them and is not covered by any gate.
