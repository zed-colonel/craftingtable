# ADR-051: Bounded design-question recovery

Status: accepted
Date: 2026-09-17

WI-01 and EXO-01 stopped at design questions mixing missing shared documents, repository
administration decisions and historical measurements. Generic Resume re-evaluated the same
report, while slice controls offered another worktree.

An explicit recovery command discovers saved context and matching source documents across
exact bound plan versions, then reserves one design continuation with operator guidance,
supporting text and an optional backend/model choice. Strict version and context hashes are
checked at reservation and launch. The original worktree, complete handoff, timeout and
permission posture remain; implementation/review profiles and remediation budgets do not
change. Optional cycle JSON preserves recovery through restart without replaying launches.

Investigation always stops for operator review. Continuation advances only through the normal
explicit no-open-questions gate. A failed or incomplete report cannot approve anything.
Collected configuration and source text never become accepted checkpoint evidence or fabricated
measurements. Remote administration and historical-environment provisioning remain separate
operator decisions. Matching identifiers are a bounded discovery heuristic, not proof that all
relevant evidence was found; the UI exposes limits and supports operator-supplied documents.

No new shell endpoint, workflow engine, agent role or merge authority is introduced. Existing
manual handoffs can still be adopted by Resume.
