# CraftingTable Development Planning Package

Read in this order:

1. `craftingtable-implementation-plan.md`
2. `craftingtable-work-breakdown.yaml`
3. `craftingtable-adapter-assumption-ledger.yaml`

The first implementation milestone is deliberately narrow: use CraftingTable to take `AQ-01` through one complete Codex implementation, deterministic verification, independent review, remediation, and human-approved local merge from a browser on the MacBook.

Planning Studio, additional backends, parallel runs, and multi-user activation are post-MVP work and are gated on successful AQ-01 dogfooding.
